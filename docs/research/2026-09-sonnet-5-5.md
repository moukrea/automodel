### 3b. Frontier on CursorBench 4.0

Points in cost order:

- **Sonnet 5.5 low 35.8 at $0.50 ✓**
- **Sonnet 5.5 medium 39.2 at $0.70 ✓**
- Opus low 43.7 at $1.17 ✓
- **Sonnet 5.5 high 47.8 at $1.67 ✓**
- Opus medium 52.5 at $2.91 ✓

- Opus high 56.0 at $3.97 ✓
- Sonnet 5.5 max 55.5 at $9.67 ✗

This is the **first Sonnet on the frontier against Opus 5.5 on both benchmarks.** Sonnet 5 was dominated at every effort.

- **Sonnet 5.5 high sits between Opus low and Opus medium on both.**
  - AA: +5 points over Opus low for 2x the cost; 81% of Opus medium's cost for −4 points.
  - CursorBench: +4.1 points over Opus low for +43% cost; 57% of Opus medium's cost for −4.7 points.
- **Sonnet 5.5 low is the cheapest non-Haiku point.**
  - AA: 75% of Opus low's cost for −6 points.
  - CursorBench: 43% of Opus low's cost for −7.9 points, with 0.64x the steps.
- **Upper efforts:** Sonnet xhigh and max are dominated, or no better than Opus high/xhigh.

### 3c. Price per token vs cost per task

- **List price** is half of Opus 5.5 for input, output and cache writes.
- **Cache reads cost the same, $0.20/M.** Long Claude Code sessions are dominated by cache reads, so the real advantage shrinks there (the same pitfall as Sonnet 5).
- **Output tokens are higher at equal effort** on the AA index: 1.4x at low, 0.75x at medium, 0.97x at high, 1.12x at xhigh, 1.62x at max. At max this cancels the price advantage.
- **CursorBench tokens per task:** Sonnet 5.5 high uses about the same tokens as Opus medium (37.4k vs 38.0k), at half the price per token.
- **Tokenizer:** the same as Sonnet 5 and, per the pricing page, the same new tokenizer family as Opus 5.5 ("Claude 4.7 and later"), so token counts compare directly.

### 3d. Does it replace Haiku 4.5 for mechanical subagent work?

The evidence is not conclusive, and the benchmarks alone don't settle it.

- **Quality:** Sonnet 5.5 low scores 36 against Haiku's 17 (reasoning variant) on v4.3.2, so more than twice the index for 1.46x the reasoning-variant cost ($0.41 vs $0.28).
- **Cost:** the catalog prices routed Haiku as it runs, without thinking, at 0.14. Sonnet 5.5 low would cost about 3x that.
- **No measurement for Sonnet 5.5 without up-front thinking:**
  - Sonnet 5.5 cannot run with thinking disabled: `disabled` returns 400.
  - `between_tools` is the nearest equivalent to how Haiku runs, but nobody has benchmarked it.
  - If the proxy "strips thinking" for Sonnet as it does for Haiku, Sonnet 5.5 returns 400.
- **Haiku has no CursorBench, AA Coding Agent or v4.3.2 no-thinking cost measurement.**
- **Other factors:** Sonnet 5.5 has a 1M window (Haiku 200K), per-turn effort, and a newer knowledge cutoff (Jun 2026 vs Feb 2025).
- **Pending:** Anthropic says Haiku 5.5 is coming "in the coming weeks" (announcement, SiliconANGLE, 9to5Mac). A Haiku decision may be better made after that.
- **Recommendation:** a ledger trial of Sonnet 5.5 low (or low with `between_tools`) as the subagent tier, rather than a benchmark-only switch.

### 3e. Routing risks specific to Sonnet 5.5 (what's new page)

- **Thinking blocks are tied to the model.** Sonnet 5.5 cannot read thinking blocks from Opus 5, Opus 5.5, Fable or Mythos, and no other model reads Sonnet 5.5's blocks. The API drops unreadable blocks silently (not billed). An Opus↔Sonnet switch in one conversation therefore loses the reasoning, as well as rebuilding the cache.
- **Prefix-binding check:** if the `system` prompt, `tools` or an earlier message changed before a replayed Sonnet 5.5 thinking block, the request returns **400**. This is on by default for accounts created on or after 2026-08-31 00:00 UTC. Opt-out: beta `thinking-binding-controls-2026-08-01` with `block_binding.prefix_mismatch_behavior:"drop_block"`, adaptive thinking only.
  - **This matters if the proxy rewrites history**, for example by inserting or removing effort-only system messages, stripping thinking, or changing `tools`.
  - Mid-conversation system messages are the sanctioned way to change instructions.
- **Account-bound thinking** (`org_locked_thinking`): blocks only work in the producing (or a linked) account.
- **Forced tool use** (`tool_choice` `any` or `tool`) returns 400.
- **Text between tool calls** now comes back in `thinking` blocks, which are empty at the default `display:"omitted"`.
- **Sampling parameters:** a non-default `temperature`, `top_p` or `top_k` returns 400.

## 4. Claude Code changes (2.1.284, installed locally)

Sources: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md and https://code.claude.com/docs/en/model-config

- **Sonnet 5.5 added and made the `sonnet` default.** Changelog: "Added Claude Sonnet 5.5 (`claude-sonnet-5-5`), now the default Sonnet model on the Anthropic API — 1M context, $2/$10 per Mtok with $0.20/Mtok cache reads".
  - The `sonnet` alias, and therefore `opusplan`'s execution phase and Agent-tool `model:"sonnet"` subagents, now resolve to Sonnet 5.5 on first-party.
  - Consequence: automodel's catalog `alias = "sonnet"` must move from `claude-sonnet-5` to `claude-sonnet-5-5`, and Sonnet 5 can no longer be reached through the alias.
- **Default model unchanged:** still Opus 5.5 for Pro, Max, Team, Enterprise and the API.
- **Default effort per model in CC:** Opus 5.5 medium, **Sonnet 5.5 medium**, Opus 4.7 xhigh, others high.
- **Relevant to automodel.** Changelog: "Fixed the Explore subagent switching to Opus on the Claude API when the session runs a model ID Claude Code doesn't recognize, such as a custom model behind a proxy; Explore now inherits that model".
  - Explore subagents in routed ("jev") sessions now inherit the custom model instead of going to Opus, so they will reach the proxy as the routed model.
  - Check that the hooks and proxy handle this. It is a behavior change against the "Claude Code facts" in `sources.md`.
- **`/effort` keybindings:** 2.1.284 also adds `effortSlider:*` keybinding actions. Not relevant to routing.

## 5. Decision (catalog of 2026-09-28)

- **Subagent scope: new tier `sonnet-low`** (Sonnet 5.5 at low), between `haiku` and
  `opus-low`, for reading and reporting (summaries of files, diffs and logs,
  explaining code, questions answered from a few files). Sonnet 5.5 low is on the
  convex hull of the index: the Haiku–Opus low line gives 33.5 at $0.41, Sonnet 5.5
  low scores 36. `opus-low` keeps small changes and checks that need judgment.
- **No tier for Sonnet 5.5 high**: it is on the frontier but below the convex hull
  (the Opus low–medium line gives 48 at $1.08; it scores 47), so a mix of the two
  Opus tiers does better for the same spend.
- **No main tier**: the main session stays on Opus 5.5. A switch to Sonnet 5.5
  rewrites the cache, loses the thinking blocks (neither model reads the other's),
  and cache reads, which dominate long sessions, cost the same $0.20/M. `[model:sonnet]`
  still pins it on request.
- **Aliases**: `sonnet` moves to Sonnet 5.5 (Claude Code 2.1.284); Sonnet 5 keeps
  `dominated`, without an alias.
- **Haiku 4.5 stays** the mechanical tier (priced as it runs, 0.14): nothing measures
  Sonnet 5.5 without thinking, and it can't disable thinking (400). Haiku 5.5 is announced.
